4. Pliki cookie i pamięć przeglądarki

  • Narzędzie nie używa plików cookie — ani własnych, ani zewnętrznych. Dlatego nie wyświetlamy banera zgody.
  • Strona nie ładuje czcionek ani bibliotek z zewnętrznych serwisów (są hostowane razem ze stroną). Skrypt statystyk Vercel Web Analytics jest ładowany z tej samej domeny, nie ustawia cookies ani identyfikatorów użytkownika.
  • Pamięć przeglądarki (sessionStorage / localStorage) jest używana wyłącznie do przechowania Twojego tokena API na Twoim urządzeniu — localStorage tylko wtedy, gdy sam zaznaczysz opcję „Zapamiętaj token w tej przeglądarce". Token usuniesz przyciskiem „Rozłącz i usuń token" albo czyszcząc dane strony w przeglądarce.

Przysługuje Ci prawo dostępu do danych, ich sprostowania, usunięcia, ograniczenia przetwarzania, przenoszenia, sprzeciwu wobec przetwarzania opartego na prawnie uzasadnionym interesie oraz wycofania zgody w dowolnym momencie (bez wpływu na zgodność z prawem przetwarzania przed wycofaniem). Masz też prawo wnieść skargę do Prezesa Urzędu Ochrony Danych Osobowych (ul. Stawki 2, 00-193 Warszawa). Żądania kieruj na adres e-mail Administratora. W praktyce jedynymi danymi, które pozwalają Cię zidentyfikować, są dane z formularza kontaktowego i korespondencji e-mail.

6. Zautomatyzowane decyzje i profilowanie

Nie podejmujemy decyzji opartych wyłącznie na zautomatyzowanym przetwarzaniu i nie profilujemy użytkowników.

7. Bezpieczeństwo

Połączenie ze stroną i z API BASE jest szyfrowane (HTTPS). Serwer proxy przepuszcza wyłącznie sześć metod API niezbędnych do eksportu i importu pól tekstowych; inne metody są odrzucane. Kod Narzędzia jest publiczny i możesz go zweryfikować w repozytorium.

8. Zmiany polityki

Aktualna wersja polityki jest zawsze dostępna pod tym adresem. O istotnych zmianach (np. dodaniu narzędzia analitycznego) poinformujemy przez zmianę daty i wersji na górze dokumentu.
