Problem

Opisy per kanał są w BASE. Tylko nie da się ich stamtąd wyjąć.

Jeśli sprzedajesz na kilku marketplace'ach, BASE pozwala nadpisać nazwę i opis osobno dla każdego kanału i języka. Świetnie — dopóki nie chcesz zobaczyć ich wszystkich naraz.

1

Eksport do Excela pomija kanały

Wbudowany eksport produktów wyciąga tylko pola bazowe. Nadpisania dla Allegro, Amazon.de czy Kaufland.fr zostają w BASE — niewidoczne w pliku.

2

Audyt = klikanie produkt po produkcie

Żeby sprawdzić, które oferty mają opis pisany pod kanał, a które lecą na surowym opisie bazowym, trzeba otworzyć każdy produkt i każdą zakładkę osobno.

3

Masowa poprawka nie istnieje

Copywriter, tłumacz albo AI poprawiły 2 000 opisów w Excelu? Do BASE wracają ręcznie. Albo przez API, które ktoś musi oprogramować.

Jak to działa

Cztery kroki. Bez instalacji, bez rejestracji.

Wszystko dzieje się w przeglądarce. Jedyne, czego potrzebujesz, to token API z Twojego konta BASE — instrukcja niżej.

1

Wklej token

Narzędzie łączy się z Twoim kontem i pobiera listę katalogów oraz kanałów, które masz podpięte w BASE.

2

Wybierz kanał i język

Allegro, Amazon DE, Kaufland FR, eBay EN, Temu… Lista buduje się z Twojego katalogu — widzisz dokładnie to, co masz w BASE.

3

Pobierz XLSX

Cały katalog albo wybrane SKU. Nazwa, opis, liczba znaków i kolumna Źródło mówiąca, skąd wzięła się każda wartość.

4

Popraw i wgraj z powrotem

Ten sam plik, poprawione komórki. Narzędzie pokazuje podgląd zmian, robi kopię zapasową i dopiero po potwierdzeniu zapisuje w BASE.

Kaskada opisów — dlaczego kolumna „Źródło" jest ważna

BASE trzyma treści pod kluczami pole|język|kanał. Nie każdy produkt ma nadpisanie dla każdego kanału, więc marketplace dostaje pierwszą wartość, która istnieje — schodząc po kaskadzie. Narzędzie robi dokładnie to samo i mówi Ci, na którym poziomie się zatrzymało.

Import

Wgraj poprawiony plik. Bez ryzyka, że coś rozwalisz.

Import został zaprojektowany tak, żeby nie dało się przypadkiem skasować albo nadpisać nie tego, co trzeba. Zanim cokolwiek trafi do BASE, widzisz dokładnie, co się zmieni.

  • Podgląd zmian przed zapisem. Narzędzie pobiera aktualny stan z BASE, porównuje z plikiem i pokazuje „było → będzie" dla każdego pola.
  • Puste komórki są pomijane. Import niczego nie kasuje. Zmienia tylko to, co faktycznie różni się od stanu w BASE.
  • Automatyczna kopia zapasowa. Przed zapisem pobierasz XLSX ze stanem sprzed importu — w razie czego wgrywasz go tym samym narzędziem.
  • Wybierasz poziom zapisu. Nadpisanie dla kanału, tłumaczenie językowe albo wartość bazowa — świadomie, nie domyślnie.
  • Raport po imporcie. Który produkt zapisany, który zwrócił błąd i dlaczego.

Bezpieczeństwo

Twój token zostaje Twój.

Narzędzie nie ma bazy danych, kont ani logów z tokenami. Token przekazujesz w nagłówku żądania, serwer przepuszcza go do API BASE i zapomina. Cały kod jest publiczny — możesz to sprawdzić.

token w pamięci karty (albo, jeśli chcesz, w tej przeglądarce)

przekazuje żądanie 1:1, bez zapisu, bez logowania tokena; tylko 6 dozwolonych metod API
→
api.baselinker.com
odpowiedź wraca tą samą drogą do przeglądarki

Tylko potrzebne metody

Proxy przepuszcza wyłącznie odczyt katalogu i zapis pól tekstowych istniejących produktów. Nie da się nim tworzyć, kasować produktów ani ruszać zamówień, cen czy stanów.

Osobny token, który możesz usunąć

Wygeneruj w BASE token tylko dla tego narzędzia. Po skończonej pracy skasujesz go jednym kliknięciem w tej samej zakładce — bez wpływu na inne integracje.

Kod otwarty

Aplikacja to jeden plik HTML i jedna funkcja proxy. Repozytorium jest publiczne — możesz przejrzeć każdą linię albo postawić własną kopię na swoim Vercelu.

Instrukcja

Jak zdobyć token API z BASE — krok po kroku

Zajmuje niecałą minutę. Token generujesz w panelu BASE, wklejasz do narzędzia i gotowe. Potrzebujesz dostępu do ustawień konta (właściciel albo użytkownik z uprawnieniami do API).

1

Wejdź w ustawienia konta

Zaloguj się do panelu BASE. W lewym menu, na samym dole, otwórz:

Konto i inne→Moje konto

Zobaczysz zakładki z ustawieniami konta.

Zrzut ekranu: menu „Konto i inne → Moje konto"
2

Otwórz zakładkę API

Moje konto→API

Tu znajdziesz listę tokenów API podpiętych do konta — każda integracja (sklep, kurier, narzędzie zewnętrzne) może mieć własny.

Zrzut ekranu: zakładka „API" w ustawieniach konta
3

Wygeneruj nowy token

Kliknij przycisk dodawania tokena. W polu nazwy wpisz coś, po czym go później rozpoznasz, np. Opisy MAMS. Jeśli BASE pyta o uprawnienia — wystarczy dostęp do Produktów / Katalogu (odczyt i zapis). Zamówienia, magazyn i faktury nie są potrzebne.

Zrzut ekranu: formularz nowego tokena z nazwą „Opisy MAMS"
4

Skopiuj token

Token to długi ciąg znaków w formacie 1234567-8901234-ABCDEF…. Skopiuj go w całości — ikona kopiowania obok tokena albo zaznacz i Ctrl+C.

Traktuj go jak hasło: nie wysyłaj mailem, nie wklejaj na czacie.

Zrzut ekranu: wygenerowany token z ikoną kopiowania
5

Wklej w narzędziu i połącz

Otwórz narzędzie, wklej token w pierwszym kroku i kliknij Połącz. Narzędzie od razu pokaże Twoje katalogi i kanały. Jeśli zaznaczysz „Zapamiętaj token w tej przeglądarce", następnym razem nie musisz go wklejać.

FAQ

Pytania, które zadaje każdy

Czy to naprawdę jest darmowe? Gdzie jest haczyk?

Tak, w całości i bez limitów. Narzędzie powstało przy wdrożeniu dla dużego dystrybutora i uznaliśmy, że innym użytkownikom BASE też się przyda. „Haczyk" jest jeden: na dole strony jest informacja o MAMS — systemie, który masowo generuje oferty na marketplace'y. Jeśli kiedyś będziesz potrzebować nie tylko wyjąć opisy, ale też je napisać — będziesz wiedzieć, gdzie szukać.

Czy narzędzie widzi moje zamówienia, ceny, stany magazynowe?

Nie. Proxy przepuszcza tylko sześć metod API: listę katalogów, listę pól tekstowych, listę integracji, listę produktów, dane produktów i aktualizację pól tekstowych. Każda inna metoda jest odrzucana po stronie serwera, niezależnie od tego, co ma wpisany token.

Czy import może coś skasować?

Nie. Puste komórki są pomijane, a zmienione są tylko te pola, które różnią się od aktualnego stanu w BASE. Przed zapisem widzisz pełny podgląd „było → będzie" i automatycznie pobierasz kopię zapasową. Jedyne, co import robi, to nadpisuje wskazane pola tekstowe wskazanych produktów — dokładnie tak, jakbyś zrobił to ręcznie w panelu.

Ile to trwa dla dużego katalogu?

BASE ma limit 100 zapytań na minutę na token. Eksport pobiera opisy paczkami po 100 produktów, więc katalog 10 000 SKU to ok. 100 zapytań — około minuty. Import to jedno zapytanie na produkt, więc 1 000 zmienionych produktów zajmie ok. 11 minut. Pasek postępu pokazuje, na czym stoisz; nie zamykaj karty w trakcie.

Dlaczego w kolumnie „Źródło" mam „bazowy", skoro w BASE widzę opis dla tego kanału?

Najczęstsza przyczyna: opis dla kanału jest zapisany w innym języku niż ten, który wybrałeś w narzędziu. Klucz w BASE wygląda tak: description|de|kaufland_13803 — język jest jego częścią. Sprawdź wybór języka w kroku 2. Druga możliwość: opis siedzi w polu „Opis dodatkowy" zamiast w głównym — zaznacz opisy dodatkowe w kroku 3.

Temu i Amazon: część treści siedzi w „parametrach" — czy narzędzie to widzi?

Nie w tej wersji. Dla niektórych integracji BASE trzyma tytuły i bullet pointy także w obiekcie features (np. temu_title_pl, amazon_bullet_1_pl). Narzędzie eksportuje pola name, description i opisy dodatkowe. Obsługa features jest na liście na przyszłość.

Czy mogę postawić własną kopię?

Tak. Repozytorium jest publiczne (licencja MIT). To statyczny HTML plus jedna funkcja serverless — deploy na Vercelu zajmuje dwie minuty i nie wymaga żadnej konfiguracji ani zmiennych środowiskowych.

Nie działa / mam pomysł na funkcję. Gdzie pisać?

Na maciej.fidor@mediafy.com.pl albo jako issue w repozytorium. Jeśli coś się wysypało, dołącz komunikat błędu z narzędzia — zawiera kod błędu z API BASE, który od razu mówi, co się stało.
